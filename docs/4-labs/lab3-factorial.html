2 Create a 3-way Full Factorial CRD (with 2 subsamples per experimental unit!)

We are going to use \(r = 4\). Recall, \(t = 12\).

  1. In R, randomly sample 48 islanders from your 60 – You may want to sample 12 from each group member here, but ensure the random assignment of factors is conducted across the entire set of 48 islanders at once.

  2. Randomly assign treatments to participants in a CRD for your 3-way full factorial treatment structure (what are your 3 factors and levels?) using the tools in R learned in class.

    • See class slides for an example
    • At this point you should have a dataset with 48 rows (one for each islander), and four columns (1 column for your Islander name/id, and 3 for the factors).

  3. Double your rows from 48 to 96 – adding two subsamples for each islander – by adding a subsample column with the values 1 and 2 for each islander.

    • This does not entail applying ANOTHER treatment combo. Just recording the response twice.
    • There is provided code in the template to help you do this using expand_grid()!!
    • Your data should have 96 rows and 5 columns now.

  4. Finally, add an empty column for your outcome

    • This means your final data set should have 96 rows and 6 columns for (as an example), islander, temperature, hydration, salt, subsample, and blood_pressure.
    • Make sure you used context as your column headers (e.g., temperature instead of factor_a).

4.1 Step 1: Data Processing / Cleaning

NoteProvided Research Question – Data Processing

BP is measured in Systolic/Diastolic… this is NOT division.

  • Systolic (Top Number) Measures the pressure when the heart beats
  • Diastolic (Bottom Number) Measures the pressure between beats

BUT we want one single number for the response. So we are going to use the following:

Mean Arterial Pressure (MAP) = \(\frac{Systolic + 2\cdot Diastolic}{3}\)

Use Excel/Google Sheets or R to calculate the MAP from your recorded blood pressure. I have included code in the template to help with this.

This is actually a nice touch to what real life data collection can entail.

Important

BEFORE you move on! If you are using the provided question, for each of the subsamples, calculate the islanders MAP (you should have 96 of these). Then move onto the below.

  • You have a data set with 96 rows (2 subsamples per islander x treatment combo).
  • Think about how you need to analyze this data!
  • Aggregate/Average the your response across the 2 subsamples so you have a data set of 48 rows to analyze and your islander-level response is the average.
    • e.g.: for the provided question the response with be the average MAP
    • group_by() |> summarize()
    • Make sure you keep each unique Islander and end up with one row per Islander!
